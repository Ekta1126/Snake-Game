# Snake Game: Enhanced Edition

## Overview
An engaging and feature-rich Snake game built with Java. Inspired by the classic Snake game, this enhanced version incorporates exciting features like a skill tree, multiplayer mechanics, and quests to make the gameplay more dynamic and entertaining.

## Features
1. **Classic Gameplay**: Navigate the snake, collect orbs, and grow longer while avoiding collisions.
2. **Evolution Skill Tree**:
   - Earn experience points by collecting orbs and bugs.
   - Upgrade your snake with permanent abilities to boost gameplay.
3. **Additional Collectibles**:
   - Bugs and glowing orbs increase the variety of collectibles and offer different rewards.
4. **Dynamic Obstacles**:
   - Moving and static obstacles add complexity and excitement.
5. **Multiplayer Compatibility** (future update):
   - Compete with other snakes in real-time.
6. **Quests and Challenges**:
   - Complete objectives for rewards and progression.
7. **Beautiful Graphics**:
   - Vibrant visuals and smooth animations.

## Technologies Used
- **Language**: Java
- **Graphics**: Java Swing and AWT

## How to Play
1. Clone the repository:
   ```bash
   git clone <repository_url>
   ```
2. Compile and run the game:
   ```bash
   javac Main.java
   java Main
   ```
3. Controls:
   - **Arrow Keys**: Control the snake's movement.
   - **P**: Pause or resume the game.
   - **Enter**: Restart the game after a game-over.
4. Objectives:
   - Collect orbs and bugs to grow longer.
   - Avoid colliding with walls, obstacles, or your own tail.
   - Unlock skills and upgrades using earned experience points.

## Game Modes
- **Single Player**: Play against the environment and set high scores.
